02 — Setup

Installed before standup ends.

One binary, no sidecars, no service mesh rewrite. Most teams get their first correlated incident view on day one.

01

Drop in the agent

A single static binary per host, or one DaemonSet for Kubernetes. It auto-detects runtimes, containers and cloud metadata.

curl -sSL nordveil.sh | sh
02

Connect your sources

Point your existing OTel exporters at us, then link GitHub and your cloud accounts. Deploys and infra changes join the timeline automatically.

nv connect github aws
03

Let baselines settle

Seven days of traffic teaches Nordveil what normal looks like. Then alerting flips from thresholds you guessed to behaviour you actually have.

nv baseline --status
